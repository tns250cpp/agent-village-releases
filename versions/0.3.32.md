# 0.3.32

- 공개 배포용 Windows 실행파일에서 개발 PC의 사용자 폴더와 빌드 경로를 일반 경로로 치환했습니다.
- 버전 안내와 Windows 다운로드를 위한 공개 배포 저장소를 제공합니다.
- portable 실행파일과 설치파일을 함께 제공합니다.

## 다운로드

- 설치 없이 실행: `Agent-Village-3D-0.3.32-portable.exe`
- Windows 설치: `Agent.Village_0.3.32_x64-setup.exe`
- 파일 무결성 확인: `SHA256SUMS.txt`

Windows 10/11 x64 및 Microsoft Edge WebView2가 필요합니다. 실제 AI 작업에는 Codex 로그인이 필요합니다.
